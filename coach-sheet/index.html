Coach Sheet Autofill

Coach Sheet Autofill is a private, single-user tool. It fills in one workout log spreadsheet, shared between an athlete and a coach, with workout and recovery figures that the athlete's own fitness tracker already records.

Privacy policy

The tool asks Google only for access to files the user picks with Google's file picker, and the only file picked is that one workout log. It cannot see any other file in the user's Google Drive.

It reads the log to find the right rows and writes the athlete's own workout figures into them. Nothing is sold, shared with anyone else, used for advertising, or used to train any model. The tool keeps no copy of the spreadsheet; it stores only a note of which rows it has already filled.

Access can be withdrawn at any time from the Google Account's "Third-party apps and services" page, which stops the tool immediately.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
